# Граф базы знаний

Локальный просмотрщик графа: источники, узлы и связи из JSON-файла.

В репозитории вымышленный набор `kb.example.json`.

## Запуск

```bash
npm install
npm test
npm run dev
```

Сборка: `npm run build`. Каталог `dist` в git не попадает.

## Свой файл

Кнопка «Открыть JSON» читает файл только в браузере. Он не отправляется на сервер и не записывается в проект.

Файл `kb.json` рядом с кодом указан в `.gitignore`. Не подключайте его к импортам и не копируйте в `dist` перед публикацией.

Ожидаемые массивы: `sources`, `nodes`, `edges`. У источника и узла есть `id` и название, у связи — `from`, `to` и `type`.
